# KeyboardTraining Tool
Inspired by the Keyboard Testing Page by danwlker https://github.com/danwlker/KeyboardTestingPage/
This is built to assist with user training when changing a phsycial keyboard layout by giving a scalable local webpage you can place modal at the bottom of your screen to see what you are pressing, see what is where, and assist with reprogramming muscle memory.
View at: https://pedanticavenger.github.io/KbdTrainer/
